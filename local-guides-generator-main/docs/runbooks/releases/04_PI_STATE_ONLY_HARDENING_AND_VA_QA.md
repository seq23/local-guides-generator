# PI Canonical Citation Remediation + VA QA

This document explains the canonical PI answer shape after the citation-remediation pass.

## State pages must now include
- a sponsor-safe best-lawyer block
- a how-to-choose checklist
- a comparison table
- the neutral state directory
- the attorney discipline and license lookup

## State page rules
- never say a firm is "the best"
- do not rank firms
- do not mention city pages as the intended next step
- keep the directory above discipline lookup
- keep the comparison/selection blocks above the directory

## Canonical PI guides must now do three things early
1. answer the question directly
2. include a query-matching H2
3. show a checklist, table, or numbered framework before long prose

## VA red flags
Stop and escalate if you see:
- city-by-city wording added back onto PI homepage or state pages
- rankings, outcomes, ratings, or "top 10" language
- long intros before the first checklist on canonical PI guides
- any edit that moves discipline lookup above the state directory
