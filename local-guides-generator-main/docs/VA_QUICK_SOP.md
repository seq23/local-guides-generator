# VA Quick SOP — Make a Sponsor Live

## Files
- sponsor record → `data/sponsor_intake/sponsors/<slug>/sponsor.json`
- sponsor assets → `data/sponsor_intake/sponsors/<slug>/assets/`
- live activation → `data/buyouts.json`

## Quick steps
1. Create or update sponsor record
2. Add logo, hero image, and directory CTA image
3. Add one live buyout entry to `data/buyouts.json`
4. Rebuild and validate
5. Click-audit affected pages
