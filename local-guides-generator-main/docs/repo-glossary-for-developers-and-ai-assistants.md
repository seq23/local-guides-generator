# Repo Glossary for Developers and AI Assistants

## Pack
A supported vertical site configuration selected through a page-set file.

## Guide page
A structured decision-support page generated from guide JSON.

## City page
A location page built from listing, guide, and template data for a market.

## Fanout
The query-routing layer that increases page-level relevance and destination specificity.

## Request-assistance
The provider lead-capture flow that posts to the Airtable-backed endpoint.

## Build
The process that turns source data and templates into the static `dist/` site.
