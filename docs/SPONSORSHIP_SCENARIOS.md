# Sponsorship Scenarios

## Scenario 1 — City already sold
Houston already has a city sponsor. A Texas statewide buyout arrives.

Result:
- Texas state page can still be sold
- Houston is excluded unless separately resolved
- up to 10 other selected Texas cities can be included

## Scenario 2 — Statewide buyout wants more than 10 cities
Result:
- first 10 selected cities are included
- any additional cities must be declared as paid add-ons

## Scenario 3 — Vertical buyout
Result:
- homepage hero can appear
- guides can carry sponsor influence
- CTA conversion layer can be bought out
- hero CTA must still use /next-steps/

## Scenario 4 — Standard placement only
Result:
- city + state page placements only
- no homepage
- no guides
- no CTA conversion buyout
