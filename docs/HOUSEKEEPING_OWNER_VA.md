# HOUSEKEEPING — OWNER + VA OPERATIONS MANUAL

## Daily
- Check one live sponsor page for CTA rendering, disclosure, and routing.
- Check one request-assistance path and one next-steps path.
- Check one live sponsor lead destination.

## Weekly
- Run `npm run validate:all`.
- Click-audit one city, one state, one guide, `/next-steps/`, `/request-assistance/`, and `/for-providers/`.
- Confirm no adjacent CTA surfaces render.

## Monthly
- Build a baseline ZIP from the true repo root.
- Reopen the ZIP and confirm root files exist.
- Save to Owner Google Drive if access is available, or email Owner a copy or download link.
- Review `data/buyouts.json` and active sponsor records.

## Quarterly
- Audit sponsor assets, sponsor disclosures, pricing, and CTA copy.
- Test one backup ZIP by extracting it and running validation from the extracted copy.
